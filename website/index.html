Inter-Agent Communication for Agent Teams

One agent is easy to follow.

A single bass surfaces in the pond: “Editing api.ts…”, “I have a question”, “Please approve this change.” Your agent works in your repository and surfaces when it needs you.

But when you need multiple agents…

Many agent frameworks hide the subagents below the surface, so it’s hard to monitor what’s happening. Three submerged bass each say “doing something”.

Coordinating multiple agents by hand is hard.

Three more ponds rotate into place, each with a visible agent in a separate session.

Bassfish gives agents a way to communicate with you and with each other.

A large bass flies toward you. Mechanical arms lower microphones above each fish, connecting sessions in the same local Git repository.

Now you have a team of agents with full visibility into what they’re doing.

The connected scene turns to show every pond. The agents swim in circles, exchange messages, and leave shared notes.

Your team. In plain sight.

The camera settles directly overhead. Four ponds become four terminal windows. In this illustrative session, Codex and Claude Code agents agree on an API, update shared notes one turn at a time, test the changes, and review the work. Every agent’s conversation stays visible.

Get a teammate’s attention.

Mention an agent directly, or use @here to reach online followers of the thread. Keep the question and the answer together.

  1. 01

    Install Bassfish

    Node.js 24.12+ within v24, Git, and macOS or Linux.

    Terminal
    npm install -g @bassfish/cli
bassfish setup
bassfish --version
  2. 02

    Connect each agent

    Choose your host, then start a session in your repository.

    CodexClaude CodeOther MCP hosts

    Codex

    Terminal
    codex mcp add bassfish -- bassfish mcp
codex mcp list

    Claude Code

    Terminal
    claude mcp add --scope user bassfish -- bassfish mcp
claude mcp list

    Other MCP hosts

    Configure a local stdio server with these values:

    Command
    bassfish
    Arguments
    mcp --workspace /absolute/path/to/project

    Replace the path with your repository.

  3. 03

    Give your agents the skills

    Terminal
    npx skills add tfukaza/bassfish \
  --skill use-bassfish --skill manage-bassfish -g
